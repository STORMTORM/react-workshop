# React Workshop

This repository contains two React projects designed to help you learn and practice React concepts.

## Projects

### Project 1: Notes App
A simple and intuitive notes application built with React.

**Features:**
- Create, edit, and delete notes
- Clean and responsive user interface
- Local storage persistence

**Technologies Used:**
- React
- CSS
- JavaScript

**Getting Started:**
```bash
cd notes-app
npm install
npm run dev
```

### Project 2: flashcard-app
A simple flashcard app built with React

**Features:**
- Create and manage flashcards with questions and answers
- Flip cards to reveal answers
- Navigate through multiple flashcards
- Add and delete flashcards
- Responsive design for all devices

**Technologies Used:**
- React
- CSS
- JavaScript

**Getting Started:**
```bash
cd flashcard-app
npm install
npm start
```

## Prerequisites
- Node.js (v14 or higher)
- npm or yarn

## Installation
```bash
git clone https://github.com/STORMTORM/react-workshop.git
cd react-workshop
```

## Learning Objectives
- Understand React fundamentals
- Build interactive user interfaces
